# Christian Boyles — Software Engineer Portfolio

Personal developer and product design portfolio of **Christian Earl James Boyles** — Junior Software Engineer specializing in **UI/UX Systems, Frontend Architecture, and Backend Engineering**.

## Architecture & Highlights

- **Editorial Field Manual Aesthetic:** Warm archival Daylight palette (`#F6F3EC`) and matte carbon Darkroom mode (`#121110`) with Signal Vermilion (`#C43B1B` / `#EA623E`) accents—paired with *Instrument Serif*, *Plus Jakarta Sans*, and *JetBrains Mono*.
- **Interactive 3-Lens Discipline Inspector:** Hero specimen toggling a live room-hold component across **UI/UX Specs**, **Frontend React State**, and **PostgreSQL Row-Level Security (RLS)**.
- **Two-Tier Work Showcase:** Editorial spreads for featured flagships (*Kheryne*, *MAPAGUAPA*, *Ryde*, *Amaranth*) + an interactive hover-preview archive ledger (*BoardMap*, *RESEATO Cebu*, *Lily Flowers*).
- **Deep-Linkable Case Study Drawer:** URL-synced (`#project=<slug>`), focus-trapped, and keyboard-navigable (`←`/`→`/`Esc`) with grouped multi-platform screen galleries.
- **`⌘K` Command Palette:** Fast keyboard navigation across projects, sections, theme switching, and contact actions.

## Development

```bash
npm install

npm run build
```

## Adding Your Completed Resume PDF

1. Place your finished PDF in `public/resume.pdf`.
2. In `src/content.ts`, set `PROFILE.resumeUrl = "/resume.pdf"`.
